# Игры разума

Игры разума — это набор из пяти консольных игр, предназначенных для тренировки вашего мозга. Каждая из игр предлагает вопросы, на которые необходимо дать правильные ответы. После трех правильных ответов игра считается пройденной. Неправильные ответы завершат игру и предложат вам пройти ее заново.

### Игры:

- Калькулятор. Арифметические выражения, которые необходимо вычислить.
- Прогрессия. Поиск пропущенных чисел в последовательности чисел.
- Проверка четности: Определение, является ли заданное число четным.
- Наибольший общий делитель: Нахождение общего делителя двух чисел.
- Простое число: Определение, является ли заданное число простым.

### Настройка

```bash
make install
```

### Игра калькулятор

В этой игре вам предстоит вычислить сумму, разность, произведение или частное двух чисел. Игра завершится после трех правильных ответов.

#### Запуск игры калькулятор

```bash
make brain-calc
```

### Игра "проверка на чётность"

В этой игре вы должны ответить "yes" или "no" на вопрос, является ли предложенное вам число четным. Игра завершится после трех правильных ответов.

#### Запук игры "проверка на чётность"

```bash
make brain-even
```

### Игра "общий делитель"

В этой игре вам нужно найти наибольший общий делитель двух чисел. Игра завершится после трех правильных ответов.

#### Запуск игры "общий делитель"

```bash
make brain-gcd
```

### Игра "простое число"

В этой игре вам предстоит ответить "yes" или "no" на вопрос, является ли предложенное вам число простым. Игра завершится после трех правильных ответов.

#### Запуск игры "простое число"

```bash
make brain-prime
```

### Игра "прогрессия"

В этой игре вам предстоит найти недостающее число в предложенной прогрессии. Игра завершится после трех правильных ответов.

```bash
make brain-progression
```
